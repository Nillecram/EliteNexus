JSON Schema (draft 2020-12) per journal event, written for code generation; covers events
since Odyssey (manual v31+) including undocumented ones (Colonisation*, PowerplayMerits/Rank,
CarrierLocation, SquadronCarrier "CarrierType", LaunchVessel, GameModeChange, ...).
Fields are mostly un-validated (no enums) by design; Status/Status.json documents the
Status.json flags. See docs/research/journal.md.
