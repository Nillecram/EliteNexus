Odyssey glare and dark exposure

Tame the glare of cockpit lights and lift the darks with the game's own tone-mapping values.

Why Odyssey looks dark outside

Odyssey's auto-exposure (brightness adaptation) reacts to the cockpit's own lights. With a bright dashboard in view, everything outside the canopy is drawn darker. The game has no switch for it, so players change the values it's built from instead, in GraphicsConfigurationOverride.xml.

What you can set

  • Glare from lights (GlareCompensation). The game uses 1.33; lower means less glare around bright lights.
  • Standard ACES curve. Draws darks and mid-tones brighter than the game's own curve, with highlights the same. The page shows by how much.
  • Auto-exposure targets: the three Percentiles the exposure is set from.

Presets to start from: Game default, Less glare (glare 1.0) and Morbad's Odyssey tweak (CMDR Morbad's 2021 forum settings). The game's own values are read from your install.

An experiment, honestly labelled. Frontier doesn't document these values. They change the whole picture (space, stations, planets), the game reads them only when it starts, and Game default + Apply puts the game's own values back. Only the values you change are written, and your original file is copied aside first. To dim the cockpit lamps themselves, use the cockpit-light dimmer; Bloom in the game's graphics options sets how much bright lights glow.
