Dim the Elite Dangerous cockpit lights

The game has no setting for its cockpit lights. Elite Nexus dims the cockpit's own lamps and glow, and nothing else.

Why the cockpit is so bright

In Odyssey the cockpit's own lamps light the dashboard brightly, and the auto-exposure reacts to them, so space and planets outside look darker. There's no option in the game to turn those lamps down.

How the dimmer works

  • Elite Nexus installs 3Dmigoto (a Direct3D 11 hook, open source, GPL-3.0) next to the game, downloaded from its official GitHub release and checked against pinned checksums.
  • A pattern adjusts the game's light shader as the game loads it: lights within a reach of your eyes (about 5 m covers most cockpits) keep only the share of light you choose.
  • Stations, carriers, planets and the HUD stay as they are.
  • Elite Nexus never copies the game's code. The pattern finds the light shader by what its code looks like, so most game updates don't break it. If one does, the dimmer simply stops until Elite Nexus is updated.

In-game keys

KeyWhat it does
F9Dimmer on or off
F10Light kept: 0, 15, 35, 60 or 100 %
F11Reach: 5, 8 or 12 m

They work while the game window is in front, without Shift, Ctrl or Alt. If your control presets already use one of these keys on its own, the tab names the action, because pressing the key would then do both.

Install and remove in one click

Install the dimmer first says exactly what will happen. Remove takes out exactly the files that were installed (any that changed since are left in place) and the files 3Dmigoto made. The same install is the graphics hook that lets HUD colours keep hostile red, friendly green and shield blue.

Good to know. 3Dmigoto can't run alongside EDHM or another 3Dmigoto mod; the tab tells you if one is there. Frontier tolerates mods like this without having approved them. Settings saved in the tab apply the next time the game starts.
