Dim the cockpit lights. Tame Odyssey's glare.

The game has no setting for its cockpit lights. Elite Nexus dims the cockpit's own lamps and nothing else, with in-game keys (F9, F10, F11). For glare and dark exposure it sets the game's own tone-mapping values, starting from community presets.

Fast, and careful with your game

  • Fast. Written in Rust with a GPU-drawn interface: no browser engine, Python or Node.js. Your whole journal history loads in well under a second, and it follows the game every 100 ms.
  • One exe. Unzip and run. Everything it keeps lives in a nexus-data folder next to it, so it's easy to move or remove.
  • Read-only journals. Your journals are only ever read. Game settings change only when you click, only the values you change, and your original file is kept.
  • Opt-in uploads. EDDN, EDSM, Inara and EDAstro are off until you switch them on, and only live events are sent, never your history. API keys are encrypted with Windows DPAPI.
  • Honest about its data. Pages say where numbers come from and what they can't show, for example why "no record" of a species isn't proof nobody sampled it.

Questions

Is it free?

Yes: no ads, no account, no subscription. It's open source under the GNU GPL version 3 or later, and the source code is on GitHub.

How do I install it?

Download the zip from the latest release, unzip it anywhere and run EliteNexus.exe. It finds your journal folder by itself. Start it before or after the game. Windows may warn about an app from an unknown publisher the first time; choose "More info", then "Run anyway".

Can I change the HUD colour without hostile contacts changing colour?

Yes. Switch on "Keep hostile red, friendly green and shield blue" on the HUD colours tab. It needs Elite Nexus's optional graphics hook (3Dmigoto), installed and removed in one click, and it can't run alongside EDHM. More about HUD colours.

Is it allowed?

Elite Nexus reads the journal files Frontier writes for third-party tools, and HUD colours and glare use the game's own settings file. The optional dimmer and colour protection use 3Dmigoto, which Frontier tolerates without having approved it. Nothing in the game's own files is changed.

Does it replace EDMC, EDDiscovery or Observatory?

For many commanders, yes; for some, not yet. See how it compares, including what other tools still do better.

Consoles, Mac or Linux?

Windows only. It reads the journal files that the PC game writes.

Where do I report a bug or ask for a feature?

Open an issue on GitHub.
